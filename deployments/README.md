# Deployments

One file per chain, recording what is live, at which commit, and where its verification input is.

**Nothing here yet.** These contracts have never been deployed to mainnet. When the first
deployment happens it is recorded in `4663.json` before anything is announced, because an address
that exists only in somebody's terminal history is an address nobody else can check.

The v1 contracts are live and are recorded in the `aindex-contracts` repository, not here. They
are a different product on different addresses and are not superseded by anything in this repo
until a migration actually runs.
